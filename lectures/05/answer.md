- 検索だけを実行して見つかったページと、その本文で確認できたこと：ベクトル検索だけだとダメ。
- `--trace`で見えたツール呼び出し（ツール名・引数・回数、Treeでたどった目次など）：search_graph、browse_tree、search_materialsなどのツールを使った。それ以外は上記回答済み。
- 取得した情報が足りなかった例、取得できたのに回答へ使えなかった例： uv run python -m app.retrieval "LoRA QLoRA 違い"だけだと全然ダメだった。--traceも効かなかったが、そもそも回答がダメ。
- 今回の用途に採用したい方式と、その理由・比較条件の限界：速度差はそれほどない、でも「それほど」の部分がコストに出ているので、RAGかGraphを使いたいが、node作成にかかる工数を考えると、RAGになると思う。
- 気づき・疑問：GraphRAG化するときの手順や想定労力を調べたい。既にRAG化したオリジナル用途があるが、これを簡便にGraph化し精度を上げられるのかが注目している点。
